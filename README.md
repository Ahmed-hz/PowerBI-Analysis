# 📊 لوحات معلومات باور بي آي — مشاريع تدريبية
# Power BI Dashboards — Training Projects

> **ع:** مجموعة لوحات معلومات تفاعلية تم بناؤها خلال برنامج تدريبي في تحليل البيانات. يُظهر كل مشروع مهارات النمذجة، حسابات DAX، والسرد البصري للبيانات باستخدام بيانات بسياق سعودي.

> **EN:** A collection of interactive Power BI dashboards built during a data analytics training program. Each project demonstrates data modeling, DAX calculations, and visual storytelling using Saudi-themed datasets.

---

## 1️⃣ لوحة المنشآت في المملكة | Saudi Establishments Dashboard

![Establishments Dashboard](establishments.png)

**ع:** لوحة تحليلية تستعرض توزيع وخصائص المنشآت التجارية عبر مناطق المملكة العربية السعودية.

**EN:** An analytical dashboard exploring the distribution and characteristics of business establishments across Saudi Arabia's regions.

**المهارات | Skills:**
- تقسيم البيانات الجغرافية | Geographic data segmentation
- بطاقات مؤشرات الأداء | KPI cards and summary metrics
- تصفية تفاعلية حسب المنطقة | Interactive filtering by region

📁 `المنشآت_في_المملكة.pbix`

## 2️⃣ لوحة معلومات العقارات | Real Estate Dashboard

![Real Estate Dashboard](realestate.png)

**ع:** لوحة تحليلية لبيانات سوق العقارات تشمل أنواع العقارات، اتجاهات الأسعار، والتوزيع المناطقي.

**EN:** A dashboard analyzing real estate market data including property types, pricing trends, and regional distribution.

**المهارات | Skills:**
- تحليل اتجاهات الأسعار | Price trend analysis
- تقسيم حسب نوع العقار | Property type segmentation
- تحليل مقارن بين المناطق | Comparative regional analysis

📁 `لوحة_معلومات_العقارت.pbix`

## 3️⃣ لوحة المبيعات | Sales Dashboard

![Sales Dashboard](sales.png)

**ع:** لوحة أداء المبيعات تتتبع الإيرادات، الوحدات المباعة، وأداء المنتجات عبر المتاجر والفترات الزمنية.

**EN:** A sales performance dashboard tracking revenue, units sold, and product performance across stores and time periods.

**المهارات | Skills:**
- تحليل الإيرادات والحجم | Revenue and volume analysis
- اتجاهات السلاسل الزمنية | Time-series trends
- مقارنة على مستوى المتاجر | Store-level comparison
